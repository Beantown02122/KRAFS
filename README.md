# KRAFS Website

KRAFS — Kreating Real Art From Scratch.

This is the GitHub Pages starter site for the KRAFS clothing brand. It recreates the approved bright urban graffiti direction with KRAFS artwork, streetwear campaign imagery, category panels, new arrivals, a seasonal campaign, brand story and email signup.

## Files

- `index.html` — homepage
- `css/style.css` — responsive website styling
- `js/main.js` — simple interactions
- `assets/images/hero-krafs.jpg` — graffiti hero
- `assets/images/categories.jpg` — category artwork
- `assets/images/products-campaign.jpg` — product and seasonal artwork
- `assets/images/krafs-banner.jpg` — K / R / A / F / S graffiti band

## Upload to GitHub

1. Extract this ZIP.
2. Upload ALL files and folders to the root of your GitHub repository.
3. Keep the folder structure exactly as supplied.
4. In GitHub open Settings → Pages.
5. Under Build and deployment choose `Deploy from a branch`.
6. Choose `main` and `/ (root)`.
7. Save.

## Current status

This is a visual storefront prototype. The shopping bag, quick shop and email signup demonstrate interactions but do not process payments or save customer information.

Before selling products, replace placeholder product information and connect a real ecommerce/checkout service.
